# 営業リスト一括メール（mail-blast）

スプレッドシートの営業リストから、**1通ずつ個別に**メールを送るツール。
BCC でまとめて送るのではなく、1宛先ずつ送る。
相手の受信箱には、その1社だけに宛てた普通のメールとして届く。

差出人はこれまで手で送っていたのと同じ **poyapiyotonemuneko@gmail.com**。
Gmail の SMTP でそのまま送るので、相手から見た差出人も、返信の届く先も今までと変わらない。
差出人の住所・連絡先は `lib/business/site.ts` を直接読んでいるので、二重管理にはならない。

---

## 1. 準備（初回だけ）

Gmail は普段のパスワードでは外部から送信できない。**アプリパスワード**を発行する。

1. Google アカウント → セキュリティ → **2段階認証プロセスを有効にする**（未設定なら）
2. https://myaccount.google.com/apppasswords で
   アプリ名を「mail-blast」などにして作成し、表示された **16桁**を控える

`tools/mail-blast/.env` を作って書く。

```
GMAIL_USER=poyapiyotonemuneko@gmail.com
GMAIL_APP_PASSWORD=xxxxxxxxxxxxxxxx
```

- 16桁は空白を抜いて貼る。
- `.env` は `.gitignore` 済み。リポジトリには入らない。
- 差出人の表示名を変えたいときだけ `BUSINESS_MAIL_FROM=Japan Trip Picks <poyapiyotonemuneko@gmail.com>` を足す。

書けたら、ログインできるか確かめる（1通も送らない）。

```bash
node tools/mail-blast/mail-blast.mjs verify
```

> 独自ドメイン（例 info@japantrippicks.com）から送りたくなったときは、
> `.env` を `RESEND_API_KEY` と `BUSINESS_MAIL_FROM` に差し替えれば Resend 経由に切り替わる。
> サイトの問い合わせフォームと同じ送信基盤。gmail.com は Resend の差出人にはできない。

## 2. リストを書き出す

スプレッドシート「直営業9月」で
**ファイル → ダウンロード → カンマ区切り形式（.csv）**。

列は `日付 / 店名 / エリア / ジャンル / 公式URL / 問い合わせ手段` のままでよい。
見出しが多少違っても（`会社名`、`メールアドレス` など）拾えるようにしてある。

## 3. 送れる相手と、手でやる相手に振り分ける

```bash
node tools/mail-blast/mail-blast.mjs prepare --in "C:/Users/miyul/Downloads/直営業9月.csv"
```

「問い合わせ手段」の欄からメールアドレスを取り出して、2つのファイルに分ける。

| ファイル | 中身 |
| --- | --- |
| `data/recipients.csv` | メールが取れた相手（＝一括送信の対象） |
| `data/manual-follow.csv` | フォーム・電話しかない相手（＝手で問い合わせる分） |
| `data/already-sent.csv` | **日付が入っている行**（＝手作業でもう送った分）。対象から外す |
| `data/duplicates.csv` | 同じアドレスが2行以上あって除外した分 |

**日付列が対応済みの印**なので、日付が入っている行は自動で除外する。
送ったらスプレッドシート側に日付を入れておけば、次に prepare したとき対象から消える。
（どうしても含めたいときだけ `--include-sent`）

`recipients.csv` は Excel で開いて手を入れてよい。送りたくない行は**行ごと消す**。

## 4. 文面

文面は2本ある。**送る相手で使い分ける。**

| ファイル | 相手 | 自動で付く資料 |
| --- | --- | --- |
| `templates/default.txt` | 店舗・施設 | 店舗向け（**価格あり**） |
| `templates/agency.txt` | 代理店・支援会社 | 代理店向け（**価格なし**） |

代理店に価格ありの資料を送ると、上乗せして売れなくなる。取り違えないよう、
**どの文面にどの資料を付けるかはコード側で固定してある**（`mail-blast.mjs` の `DEFAULT_ATTACHMENTS`）。
代理店向けを使うときは `--template tools/mail-blast/templates/agency.txt` を付ける。

宛名は店名を差し込まず「ご担当者さま」で固定。1行目が件名、空行を挟んで本文。
文面を変えたいときはこのファイルを直す。

差し込みが必要になったときは `{{列名}}` と書けば CSV の列が入る
（`{{担当者名|ご担当者}}` のように `|` の後ろは空欄のときの既定値）。
列名は **CSV の見出しと完全一致**していること。違うと送信前に止まる。

## 5. 全通ぶんを目で見る（1通も送らない）

```bash
node tools/mail-blast/mail-blast.mjs preview
```

`out/preview-default.html` ができるので、ブラウザで開いて全件確認する。
差し込みに失敗した件は赤枠で先頭に出る。

媒体資料のPDFは**自動で付く**ので指定は要らない。画面にこう出る。

```
添付: JapanTripPicks_媒体資料_店舗向け_2026-08.pdf（783KB・2026-09-02更新） ← 店舗向け（価格あり）
```

**「いつの資料か」と「どっち向けか」を毎回ここで確認する。**
PPTXを直してPDFに書き出すのを忘れていると、送信前にエラーで止まる。

## 6. まず自分に送ってみる

```bash
node tools/mail-blast/mail-blast.mjs send --test 自分のアドレス@gmail.com --limit 1 --yes
```

宛先を自分に差し替えて1通だけ送る。実際の見た目・迷惑メール判定・返信先を確認する。
テスト送信は送信ログに残らない。

## 7. 本番送信

```bash
node tools/mail-blast/mail-blast.mjs send --yes
```

- `--yes` を付けないと、送信数を表示して止まる（何も送らない）
- 4秒間隔で1通ずつ送る
- 結果は `out/sent-default.csv` に残る
- 途中で止めても、**もう一度同じコマンドを叩けば送信済みは飛ばして続きから**送る
- 失敗した分も、原因を直して同じコマンドを叩けば再送される

### よく使うオプション

| オプション | 意味 |
| --- | --- |
| `--template <file>` | 文面を切り替える（浅草用・伝統工芸用など） |
| `--campaign <name>` | 送信ログを分ける（既定はテンプレート名） |
| `--limit 10` | 先頭10件だけ |
| `--attach <file>` | 資料を差し替える（既定は文面ごとに自動） |
| `--no-attach` | 資料を付けずに送る |
| `--interval 3000` | 送信間隔（ミリ秒・既定4000） |
| `--skip-invalid` | 差し込みに失敗した行を飛ばして送る |

文面ごとにログが分かれるので、**同じリストに別の文面で2通目を送る**ときは
`--template` を変えるだけでよい（1通目のログには影響しない）。

## 送る前に気をつけること

- **特定電子メール法**：広告・宣伝を含むメールには、送信者名・住所・受信拒否の連絡先を
  本文に書く義務がある。テンプレートには入れてあるが、消すと `send` が止まる。
  公式サイトで公開されている法人の問い合わせ先に送るぶんはオプトイン不要（同法3条1項4号）。
- **「配信停止」と返信が来たら、必ずリストから消す**。ログではなく元のリスト側を直す。
- **送ったらスプレッドシートに日付を入れる**。それが唯一の対応済みの記録になっている。
- **1日の通数**：無料 Gmail の上限は 500通/日。いまのリスト（100件弱）なら余裕がある。
  ただし上限に当たると `Daily user sending limit exceeded` で失敗するので、
  そのときは翌日に同じコマンドを叩けば残りから再開する。
- **短時間の連投は避ける**。既定で4秒間隔にしてある。速くしたいときも `--interval` は
  2000 くらいまでにとどめる（Gmail に一時的な送信制限をかけられることがある）。
- **店舗向けは1日10件まで**（営業ルール）。`--limit 10` を付ける。
- **資料を直したら、必ずPDFに書き出し直す**。PPTXのほうが新しいと送信が止まる。
  デスクトップの `JapanTripPicks_媒体資料_*.pptx / .pdf` が正本で、
  サイト掲載用は `public/media/` にコピーを置いている（ファイル名＝URLは固定）。
- `data/` と `out/` には取引先のアドレスが入る。git には上がらないようにしてある。
